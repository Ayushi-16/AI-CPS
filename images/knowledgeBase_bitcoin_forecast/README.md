# KnowledgeBase - AI based Bitcoin Price Forecast

## Ownership
Created and maintained Ayushi Garachh and Ayan Ghosh

## Course Information
The project is created as part of the course 'M. Grum: Advanced AI-based Application Systems' by the Junior Chair for Business Information Science, esp. AI-based Application Systems at University of Potsdam.

## AI Model Characterization
- Neural Network model using TensorFlow (R² score: 0.9688 | Adjusted R²: 0.9686)
- The model predicts the daily Bitcoin closing price (in Euro) based on market volatility trends.
- Features: Open, High, Low, and Volume.
